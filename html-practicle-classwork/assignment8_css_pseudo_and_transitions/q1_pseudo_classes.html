CSS Pseudo-Classes Demonstration

Interactive examples of :hover, :focus, :active, and :nth-child().

Hover Me

:hover

Triggers when the mouse pointer hovers over an element. The link turns teal with a smooth transition.

:focus

Applies when an input receives keyboard/mouse focus. Highlights the border with a blue glow.

:active

Triggers while the element is actively being pressed down. Shrinks and changes to darker blue.
